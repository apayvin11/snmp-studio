# SNMP Studio 1.0.0

Кроссплатформенная рабочая станция для SNMP с русским и английским интерфейсом.

## Возможности

- SNMPv1/v2c/v3: GET, GETNEXT, GETBULK, WALK и SET.
- Мониторинг устройств, сохранённые команды и контрольное чтение после SET.
- MIB-браузер, визуальный конструктор и редактор с форматированием при сохранении.
- Приём TRAP/INFORM, расшифровка по MIB и журнал реальных TX/RX-пакетов.
- Встроенный демоагент, светлое и тёмное оформление, импорт/экспорт конфигурации.

## Установщики

| Система | Файл |
|---|---|
| macOS 15+, Apple Silicon | `SNMPStudio-1.0.0-macos-arm64.dmg` |
| macOS 15+, Intel | `SNMPStudio-1.0.0-macos-x86_64.dmg` |
| Ubuntu 24.04, x86-64 | `snmpstudio_1.0.0_amd64.deb` |
| Ubuntu 24.04, ARM64 | `snmpstudio_1.0.0_arm64.deb` |

Python и библиотеки приложения включены в установщики. Отдельная установка Python не требуется.

**macOS:** откройте DMG и перенесите SNMP Studio в Applications. Приложения подписаны ad-hoc; Developer ID и нотариальное заверение Apple не применялись.

**Ubuntu:** скачайте DEB для своей архитектуры и установите через APT:

```bash
sudo apt install ./snmpstudio_1.0.0_amd64.deb
# ARM64:
sudo apt install ./snmpstudio_1.0.0_arm64.deb
```

Контрольные суммы установщиков приложены в `SHA256SUMS` и индивидуальных файлах `.sha256`.
