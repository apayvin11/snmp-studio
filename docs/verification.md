# Проверка SNMP Studio 0.1.0

| Платформа | Выполнение | Тесты | Установщик |
|---|---|---:|---|
| macOS ARM64 | Нативно | 50, успешно | DMG проверен; приложение запущено из образа |
| macOS x86_64 | Rosetta 2 | 50, успешно | DMG проверен; Intel-приложение запущено из образа |
| Ubuntu 24.04 ARM64 | Нативно | 50, успешно | DEB установлен; GUI проверен через X11/Xvfb; пункт меню и иконка присутствуют |
| Ubuntu 24.04 amd64 | QEMU x86_64 | 50, успешно | DEB установлен в чистую Ubuntu; GUI запущен; иконка и меню проверены; удаление успешно |

Интеграционные проверки включают реальный локальный UDP-обмен GET/SET/WALK, SNMPv3 SHA-256/AES-128, Inform с подтверждением, разбиение `tooBig`, обработку отсутствующих OID, Counter64 и фактические TX/RX-байты.

GUI-проверки включают скрытый по умолчанию MIB-редактор, сохранение настройки, редактирование и сохранение файлов, «Сохранить как», сохранение позиции курсора при фоновой проверке, смену языка и оформления без потери текста.

Проверены архитектуры вложенных библиотек: 103 Mach-O файла в macOS ARM64, 43 в macOS Intel, 191 ELF-файл в Ubuntu ARM64 и 166 в Ubuntu amd64. Ошибочных архитектур не обнаружено. Runtime-исходники Linux-сборок совпали с зафиксированными контрольными суммами проекта.

macOS-приложения имеют ad-hoc подпись; проверка подписи проходит после запуска. Developer ID и нотариальное заверение в этой локальной сборке не применялись. Физическое SNMP-оборудование и Debian отдельно в этом цикле не проверялись.

Контрольные суммы четырёх установщиков находятся в `release/SHA256SUMS`. Ограничения текущей версии перечислены в [README](../Readme.md#ограничения-текущей-версии).

После удаления общего подзаголовка страниц повторно пройдены 7 GUI-проверок, выполнен запуск обновлённых бинарников всех четырёх архитектур, пересобраны установщики и обновлён SHA256SUMS.

## Демоагент: проверка исходников

После добавления GUI- и CLI-управления демоагентом на macOS ARM64 и Ubuntu 24.04 ARM64 выполнены 67 тестов. Проверены соответствие объектов встроенной демо-MIB, права community, типы/диапазоны/перечисления SET, атомарность записи, GETBULK, завершение WALK в SNMPv1, IPv6, симуляция температуры и отдельный процесс с корректным завершением. GUI-проверки включают запуск/остановку, добавление параметров без дубликатов и сохранность существующих профилей. Интерфейс дополнительно запущен через X11/Xvfb на Ubuntu.

Установщики в этом цикле не пересобирались; новый функционал доступен при запуске актуальных исходников.


## Запросы в MIB-браузере: проверка исходников

На macOS ARM64 и Ubuntu 24.04 ARM64 пройдены 89 тестов. Проверены разовые GET, GETNEXT и GETBULK с настройкой max-repetitions, запрет GETBULK для SNMPv1, обход ветки на странице браузера, реальные TX/RX, статусы «Успешно» / «Ошибка», ошибки OID и транспорта, отмена запросов и восстановление доступности элементов управления. Проверено добавление параметра из MIB с фиксированным OID, редактируемыми названием, единицей и десятичным масштабированием, а также сохранение в SQLite. Для табличных объектов не подставляется скалярный суффикс `.0`.

После настройки ширины столбцов и отображения отмены повторены проверки браузера. Интерфейс проверен в обоих оформлениях, на русском и английском, при минимальной ширине окна; на Ubuntu выполнен запуск через X11/Xvfb. Установщики не пересобирались.


## Перекомпоновка интерфейса и сверка MIB с устройством

На macOS ARM64 и Ubuntu 24.04 ARM64 успешно выполнен основной набор из 109 тестов. Дополнительно проверены полный обход без MIB, завершение доступного пространства OID, неизвестный экземпляр под скалярным OID, чтение частичного MIB, порядок OID при обходе и последние изменения компоновки ошибок.

Проверены реальные GET/GETNEXT/GETBULK и SET с контрольным чтением; полный обход SNMPv1/v2c; действия добавления по read/write с сохранением точного индекса и устройства; добавление незадокументированных OID в дерево; исчезновение и повторное появление OID; разделение наблюдений между устройствами. Ошибки и прерванные обходы не подтверждают исчезновение объектов. TRAP SNMPv1/v2c и INFORM проверены настоящими UDP-пакетами; подтверждение INFORM сохранено.

Проведён визуальный разбор страниц команд, MIB-браузера, уведомлений и настроек. Проверены оба языка и оформления, окно 1200×760, длинные названия, несколько строк SET, пустые состояния, работающий приёмник, успешный SET и сочетание ошибки запроса с диагностикой MIB. На Ubuntu интерфейс запущен через X11/Xvfb. Установщики не пересобирались.


## Действия в свойствах OID и последовательный GETNEXT

На macOS выполнены 48 GUI-проверок. На Ubuntu после исправления горизонтального сдвига строки действий повторно успешно проверены размещение и скрытие кнопок, выравнивание панели файлов и последовательный GETNEXT. Реальный интерфейс также запущен через X11/Xvfb.

Проверены переходы между документированными и неизвестными OID, выбор и раскрытие дерева, очистка мешающего фильтра, сохранение ответа, неподвижность кнопки отправки, конец диапазона, ошибка, отмена и ответ с неувеличивающимся OID. Кнопки добавления находятся справа в заголовке свойств; недоступные действия скрыты. «Открыть MIB» и «Проверить» совпадают с полем поиска по краям и высоте. Проверены оба языка и оформления в окне 1200×760. Установщики не пересобирались.


## Сохранённые команды и SET в MIB-браузере

Основной набор из 126 тестов успешно выполнен на macOS ARM64 и Ubuntu 24.04 ARM64. Дополнительно проверены импорт сохранённых команд, корректность идентификаторов, SET без загруженного MIB и компоновка формы SET в минимальном окне. После исправления компоновки повторно выполнены проверки операций MIB-браузера, переходов GETNEXT и доступности действий.

Проверены окно добавления с фиксированным OID и редактируемыми названием, устройством, типом, исходным значением и контрольным чтением; отмена без сохранения; обновление существующей записи без копирования; удаление выбранной команды при одинаковых названиях и активном поиске; ошибка SQLite без потери введённых данных; восстановление через импорт/экспорт и переназначение удалённого устройства. Ранее сохранённые команды с несколькими OID сохраняют группировку.

Проверены настоящий SET и контрольное чтение на локальном UDP-агенте, запрос и ответ в журнале, локальная ошибка типа/диапазона, подтверждение и отмена записи, отсутствие автоматических повторов SET при тайм-ауте. Ответ SET без MIB не считается доказательством доступности чтения. В результатах браузера название стоит перед OID; неизвестные объекты показывают «Нет в MIB».

Диалог и страницы проверены в обоих оформлениях, на русском и английском, в окне 1200×760. На Ubuntu выполнен запуск через X11/Xvfb. Поля, кнопки отправки и результаты SET не перекрываются. Установщики не пересобирались.


## Визуальный конструктор MIB

На macOS ARM64 и Ubuntu 24.04 ARM64 проверены создание модуля через форму, добавление веток, параметров и уведомлений, редактирование свойств и синхронизация с исходным текстом. Выполнены 9 проверок обработки MIB и 4 новых GUI-сценария; ранее существующие проверки редактора, диагностики, сохранения и переходов к исходнику также пройдены.

Проверены точечные изменения без переписывания соседних объявлений, комментарии, диапазоны, ревизии, прямые правки с Undo, конфликт между формой и исходником, повторяющиеся OID, переименование со ссылками, запрет удаления зависимостей, создание импортов и сохранность SMIv1 ACCESS / STATUS mandatory. Неподдерживаемые формы объявлений остаются доступны в исходнике. Конструктор блокируется при синтаксической ошибке, не заменяя документ упрощённым шаблоном.

Проверены оба языка и оформления, минимальное окно 1200×760, переходы между конструктором и исходником и сохранение в пользовательский файл. На Ubuntu выполнен запуск через X11/Xvfb. Установщики не пересобирались.


## MIB-расшифровка и демоуведомления

На macOS ARM64 и Ubuntu 24.04 ARM64 проверены имена OID и уведомлений, перечисления, BITS, единицы, импортированные текстовые соглашения и десятичные DISPLAY-HINT. Старые TRAP-TYPE сопоставляются с нормализованным SNMPv1 OID enterprise.0.specific. Загрузка и закрытие MIB обновляют расшифровку истории без изменения принятых значений.

Проверены реальные UDP TRAP/INFORM от демоагента к приложению и между двумя агентами, подтверждение INFORM, отсутствие повторов при неверной community, нормализация SNMPv1, приём демоагентом с отображением в приложении и переход к соответствующим пакетам журнала. Сохранены проверки обычных запросов демоагента и SNMPv3.

Интерфейс проверен в обоих оформлениях и языках при 1200×760, на Ubuntu — через X11/Xvfb. Установщики не пересобирались.

## Встроенное форматирование MIB при сохранении

Форматтер работает внутри приложения без smidump и без добавленных стандартных MIB или нативных библиотек. Вложенность локальных OID отображается четырьмя пробелами, включая таблицы и столбцы; порядок объявлений не меняется. Лексические токены, комментарии и содержимое строк сохраняются, SMIv1 не преобразуется в SMIv2. Дополнительно проверяется равенство разобранного содержимого до и после форматирования.

Проверены повторное форматирование, числовые и прямые ссылки на OID, таблицы, SEQUENCE, ограничения, перечисления, DEFVAL, уведомления, старые MACRO и EXPORTS, несколько модулей в файле и буквальная табуляция в строках. Проверены сохранение и «Сохранить как», синхронизация буфера с файлом, Undo, сбои форматирования и конфликт внешнего изменения файла. Ранее созданные установщики не пересобирались.
